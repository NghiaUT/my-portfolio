# Portfolio cá nhân

Đây là website portfolio cá nhân được xây dựng bằng React, TypeScript và Vite để giới thiệu về bản thân, kỹ năng, các dự án đã tham gia và thông tin liên hệ.

## Điểm nổi bật

- Giao diện hiện đại, tối giản và responsive
- Chia thành các section: Giới thiệu, Kỹ năng, Dự án, Liên hệ
- Hỗ trợ chuyển đổi giao diện sáng/tối
- Tích hợp hiệu ứng và hình ảnh 3D nhẹ bằng Three.js

## Công nghệ sử dụng

- React
- TypeScript
- Vite
- Three.js
- CSS

## Cách chạy locally

```bash
npm install
npm run dev
```

Truy cập http://localhost:5173 để xem website.

## Build

```bash
npm run build
```
